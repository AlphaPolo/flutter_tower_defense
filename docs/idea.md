## 汲水塔 + 淋濕/感電傳導（2026-07-09 討論定案）

> 相關地基已順手完成：雷電連鎖改為「邊結構」繪製（`chainEdges()`，
> commit ebcc67a）——屆時傳導只需疊加一次多起點擴散。

### 核心概念

水池目前只是倒影裝飾。汲水塔讓水池變成**值得搶的地形**：
搶到水池 → 解鎖「水系流派」（剋速度 + 雷電傳導奇觀）。

### 汲水塔

| 項目 | 定案 |
|---|---|
| 建造條件 | **相鄰至少一格水池**（全遊戲第一個有位置條件的塔；放置失敗要提示） |
| 攻擊 | 每 ~1.5s 對射程 ~2.5 內全體上「淋濕」，本體零傷害 |
| 定位 | 純 utility，成本壓低（~30 金） |
| 清除水池後 | 建造時檢查、之後不管（玩家花錢清是自己的選擇） |

### 淋濕效果（4 秒，重複施加刷新）

1. **速度上限鎖 1.0×**——斥候(1.8×)/小蜘蛛(1.25×)被噴瞬間變普通人。
   單塔自立的「剋速度」定位，沒有雷電塔也值得蓋。
2. **感電傳導**（見下）。

實作：`kWetEffectType` 新效果常數 + `DefaultTimerEffect`（`last` 策略
免費送刷新）+ `EnemyComponent.isWet` getter（照 `isBurning` 模式）。
速度上限需要新的 stat 運算型別（現有 slow 是乘法/固定值，沒有 cap）。

### 感電傳導（雷 × 水 combo）

雷電打到淋濕的敵人 → 電弧**傳導給附近所有淋濕的敵人**（濕＝導體）。

- **無視 chainLimit**（這就是誘因：淋濕群 = 免費連鎖網）
- 只受傳導跳距限制（暫定 2.5 格，比連鎖的 2 格略寬）
- **傷害全額**（討論定案：先不做折扣，超模再用勝率工具校）
- 傳導目標**不吃麻痺骰**（防雷+水鎖全場）
- 跟連鎖升級是乘法：連鎖負責「跳進濕群」的入口，傳導負責擴散

實作草稿（接在 `ThunderProjectile` 的連鎖結算後）：

```dart
// ① 正常連鎖（照舊，受 chainLimit 限制）→ hit
// ② 感電傳導：chainEdges 泛化成多起點（origins: hit 的位置們），
//    positions 只放「淋濕且未被 ① 命中」的敵人，limit: 無上限
//    → 邊直接 append 進 bindEdges，閃電網自動畫出來
```

### 環境生成配套

- **保底生成**：每場至少 1 水池（順便考慮至少 1 巨岩），且偏向路線
  兩格內——解「地形彩票」（沒骰到水池 = 汲水塔死按鈕）。

### 討論中已定案的細節（實作時直接採用）

- ❌ **傳導傷害折扣**——先全額，實測超模再調
- ❌ **凍結 combo**（冰 × 淋濕 = 定身）——概念保留：若之後覺得刪掉
  絕對零度後硬控不足，這是最佳補位（護欄：解凍後 4s 免疫、Boss 減免）
- ❌ 火 × 淋濕（蒸發爆傷）——元素反應完整版的事

## 陷阱點子清單（2026-07-09 腦力激盪）

### 設計原則（討論定調）

**陷阱 = 對「路徑本身」加功能，傷害留給塔。**
傷害型陷阱跟塔在同一條「傷害/金幣」軸競爭必輸：塔對每隻敵人輸出整段
路程，陷阱只有路過那 ~1 秒。渦流好用正是因為它做塔做不到的事（操縱位置）。

### 地刺重做：百分比傷害（近定案，數值待勝率工具驗證）

現況結構性弱：30 金、每 450ms 打 12 固定傷，每隻路過只吃 ~2 tick=24 點，
敵人血量每波 +40 還複利 → 相對價值逐波爛掉。

> 改成每 tick 扣**最大血量 3%**（一次路過 ≈6%），**Boss 減半**（1.5%/tick）。

- 變成唯一的「反高血」功能件：塔打固定值、地刺削百分比，軸完全錯開
- 敵人血越膨脹越值 → 與無盡 25 波後 ×1.08 複利完美咬合、永不過時
- 實作：`SpikeTrapComponent.onTrigger` 改 `dealDamage(enemy.status.totalHp * 0.03)`
- 現為 kSeason=-1 測試季，平衡自由調不用開新季

### 第一批（傷害/位移/印記/經濟）

- **地雷（手動引爆）**：埋在路上的一次性消耗品，玩家點擊引爆大範圍爆發。
  精髓在時機——渦流聚怪 → 手動起爆是夢幻組合；狙擊塔已開主動技先例。
  變體：踩滿 N 隻自動引爆，手動為進階操作。
- **回彈陷阱**：踩到沿路線往回彈 2-3 格 + 冷卻；每隻只被彈一次（標記免疫，
  防無限循環）、Boss 免疫或只彈 1 格。剋快速兵、長迷宮核心件。平衡風險
  最高，用勝率工具校。
- **詛咒陷阱（脆弱印記）**：踩過上「受傷 +25%」數秒。`vuln` 效果現成
  （冰凍霜牢在用），實作最便宜。定位＝火力網前置放大器，放殺戮區入口。
- **收費站（賞金印記）**：踩過的敵人擊殺賞金 +50%。花錢不加防禦賭殺得掉
  ——經濟建築路線，無盡後期滾雪球件。
- **陷阱升級樹**：地刺/渦流目前沒有升級樹。例：地刺 A 流血尖刺/B 減速倒鉤；
  渦流 A 吸力更強更廣/B 旋轉時造成傷害。

### 第二批（targeting/控場/連鎖/地形）

- **集火鈴（點名印記）⭐**：踩過的敵人被點名，**所有塔優先攻擊**。解「塔在
  打雜兵、薩滿在後面奶全隊」的真實痛點；玩家首次能用擺位表達 targeting
  意圖。實作小：瞄準選擇加「有印記優先」。口袋名單第一位。
- **定身樁（stasis）**：踩到原地定住 2 秒（每隻只吃一次）+ 陷阱冷卻。與減速
  不同軸（完全停止）——給狙擊靜止靶、火炮預判點；Boss 免疫或縮短。比回彈
  好平衡（不動位置、無循環問題）。
- **共鳴水晶（死亡連鎖）**：附近 2 格內敵人死亡 → 脈衝傷害周圍。把「擊殺」
  轉成「範圍傷害」，越密集越強，天生剋蟲群/巨蛛（小蜘蛛擠一坨連環炸）。
- **工兵鏟（地形轉換）**：觸發 N 次後該格永久變泥沼、陷阱消失。消耗品 →
  永久基建的獨特經濟曲線；重用 `envSlowAt`，實作近零成本。
- **誘標（假目標）**：半徑內敵人先繞去踩它再回主堡（有耐久）。不蓋牆改道，
  把敵人「借」進殺戮區。實作最重（局部 flow field 覆寫）、平衡最難——壓箱。
- **裂地符**：觸發 N 次後該格暫時隆起成牆 10 秒（波次中動態改道）。爽但
  工程重（路中變牆的尋路邊界多）——壓箱。
- **全場時停（消耗品）**：手動引爆、全場定住 1.5 秒。嚴格說是**法術**不是
  陷阱——狙擊指向技已開「玩家主動施法」的門，「消耗品法術欄」可能是下一個
  大系統（地雷/時停/緊急修堡都裝得進去）。

### 第三批（印記變體/擊殺經濟/節奏）

- **連坐印（傷害共享）**：踩過帶印 8 秒，帶印者受傷時 30% 濺給最近的另一隻
  帶印者。渦流聚團 + 連坐 = 整坨一起融化；規則一句話、湧現度高。
- **攝魂燈（擊殺蓄能）**：附近擊殺蓄能，滿 10 層送 1 個免費障礙物。把擊殺
  轉成建材，接上現有 freeObstacle 經濟（每波 +1 的延伸）。
- **節拍重錘**：每 8 秒重擊自格+鄰格（大額傷害），有可見的蓄力倒數。玩家
  用渦流/定身把怪「存」到落錘瞬間——時機型技巧件，觀賞性高。
- **獻祭火盆（風險合約）**：開波前點燃 → 下一波數量 +50%、賞金 ×1.5。
  玩家自選難度換報酬，roguelite 引擎；無盡模式重開率×。
- **重力井（預留）**：等飛行敵人做了再議——把飛行單位拉回地面幾秒的
  防空陷阱位。

### 系統級點子（跳出陷阱框）

- **每日挑戰**：固定種子（當日全球同一張地形+同一套波次組成）+ 獨立日榜。
  排行榜基礎設施現成（RTDB 分桶加一層 `daily/{yyyymmdd}` 即可），
  實作關鍵是把 `Random` 改成可注入種子（`_spawnRng`、環境生成、
  組成快取都要吃同一顆種子）。塔防留存率經典解法；與無盡榜互補
  （無盡拚上限、每日拚同題操作）。

### 口袋名單（趣味×成本×單純度）

**集火鈴、處決樁、百分比地刺** 三件組——一句話規則、直擊現有痛點
（打錯目標/薩滿奶隊/地刺太弱）；**傳染印** 第四件讓 DoT 流成型。

- **處決樁**：踩到時血量 <15% 直接處決。薩滿天敵（殘血奶不回來）、DoT 流
  收尾件；百分比門檻同樣不過時。
- **傳染印**：帶印者死亡時，把身上的持續效果（毒/灼燒/流血）傳染給周圍。
  三種 DoT 現成，讓單體 DoT 指數擴散；蟲群/小蜘蛛 = 溫床。

## 標靶樁（2026-07-10 討論定案，待實作）

> 放在路上的瞄準標記：把追蹤型塔變成「固定火力線」。
> 名稱暫定「標靶樁」（id: `beacon`），要改隨意。

### 定案規格

| 項目 | 定案 |
|---|---|
| 類型/放置 | 陷阱類（放路上、不擋路、敵人踩過無任何效果） |
| 成本/數量 | **10 金、不限數量** |
| 耐久 | **不壞**（純標記＋擋箭物） |
| 適用塔 | **火炮、噴火、狙擊** 三種 |
| 指定方式 | **各塔手動「設定標靶／解除」**（非自動鎖最近）；標靶被拆 → 該塔設定自動解除 |
| 開火條件 | **波次進行中持續朝標靶開火**（不需要有敵人；波間停火） |
| 射程 | **無限制，純方向瞄準**——火炮標靶超出射程時，朝該方向打「極限射程」的落點 |
| 主動技 | 不受影響（指向狙擊照常自主操作） |

### 各塔行為

- **狙擊**：朝標靶位置射。無貫穿＝箭中第一個敵人消失、彈道無敵人則
  **停在標靶上**；貫穿(Lv3)＝掃全彈道、**穿過標靶**到終點。地形照常擋箭
  （標靶藏巨石後也能朝它打，但箭打到巨石為止；彈道破除(B)分支免疫）
  ——與三分支全部有互動。
- **噴火**：鎖定朝標靶方向持續噴，傷害集中咽喉點、不再跟目標亂轉。
- **火炮**：持續砲擊標靶落點；超射程 → 沿方向打極限射程處。
- 投射物互動：只有**直線彈道**（狙擊箭）會被標靶擋；火炮拋物線不受影響。

### 實作註記

- `TowerType.beacon` 進 `kTrapTypes`；`BeaconTrapComponent`（無 onTrigger 效果）
- `TowerComponent.beaconTarget: BoardPoint?`；`demolishAt` 拆標靶時掃全塔清除
  同位置的 beaconTarget
- 火炮/噴火/狙擊三塔 update()：`beaconTarget != null && waveRunning` → 走
  標靶開火分支
- 狙擊箭飛行：貫穿判定加「無貫穿箭抵達標靶格即消失」
- UI（歸使用者）：資訊面板「設定標靶/解除」按鈕 → 點選場上標靶
- 平衡：kSeason=-1 測試季自由調；完成後用勝率工具驗證（持續開火的
  火炮/噴火等於免費火力區，強度要盯）
