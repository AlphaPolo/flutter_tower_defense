## 汲水塔 + 淋濕/感電傳導（2026-07-09 討論定案）

> 相關地基已順手完成：雷電連鎖改為「邊結構」繪製（`chainEdges()`，
> commit ebcc67a）——屆時傳導只需疊加一次多起點擴散。

### 核心概念

水池目前只是倒影裝飾。汲水塔讓水池變成**值得搶的地形**：
搶到水池 → 解鎖「水系流派」（剋速度 + 雷電傳導奇觀）。

### 汲水塔

| 項目 | 定案 |
|---|---|
| 建造條件 | **相鄰至少一格水池**（全遊戲第一個有位置條件的塔；放置失敗要提示） |
| 攻擊 | 每 ~1.5s 對射程 ~2.5 內全體上「淋濕」，本體零傷害 |
| 定位 | 純 utility，成本壓低（~30 金） |
| 清除水池後 | 建造時檢查、之後不管（玩家花錢清是自己的選擇） |

### 淋濕效果（4 秒，重複施加刷新）

1. **速度上限鎖 1.0×**——斥候(1.8×)/小蜘蛛(1.25×)被噴瞬間變普通人。
   單塔自立的「剋速度」定位，沒有雷電塔也值得蓋。
2. **感電傳導**（見下）。

實作：`kWetEffectType` 新效果常數 + `DefaultTimerEffect`（`last` 策略
免費送刷新）+ `EnemyComponent.isWet` getter（照 `isBurning` 模式）。
速度上限需要新的 stat 運算型別（現有 slow 是乘法/固定值，沒有 cap）。

### 感電傳導（雷 × 水 combo）

雷電打到淋濕的敵人 → 電弧**傳導給附近所有淋濕的敵人**（濕＝導體）。

- **無視 chainLimit**（這就是誘因：淋濕群 = 免費連鎖網）
- 只受傳導跳距限制（暫定 2.5 格，比連鎖的 2 格略寬）
- **傷害全額**（討論定案：先不做折扣，超模再用勝率工具校）
- 傳導目標**不吃麻痺骰**（防雷+水鎖全場）
- 跟連鎖升級是乘法：連鎖負責「跳進濕群」的入口，傳導負責擴散

實作草稿（接在 `ThunderProjectile` 的連鎖結算後）：

```dart
// ① 正常連鎖（照舊，受 chainLimit 限制）→ hit
// ② 感電傳導：chainEdges 泛化成多起點（origins: hit 的位置們），
//    positions 只放「淋濕且未被 ① 命中」的敵人，limit: 無上限
//    → 邊直接 append 進 bindEdges，閃電網自動畫出來
```

### 環境生成配套

- **保底生成**：每場至少 1 水池（順便考慮至少 1 巨岩），且偏向路線
  兩格內——解「地形彩票」（沒骰到水池 = 汲水塔死按鈕）。
